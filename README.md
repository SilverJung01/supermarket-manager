# Supermarket Product Manager

A desktop app for managing supermarket inventory, built with Python, Tkinter and SQLite.

## Features
- Add, edit and delete products
- Search products by name
- Data stored locally in SQLite
- Input validation with error messages

## Tech
Python 3, Tkinter, SQLite3 (no external libraries needed)

## How to run
1. Install Python 3
2. Run: `python main.py`

The database file is created automatically on first run.

## What I learned
- Working with SQLite and parameterized queries
- Building a GUI with Tkinter and Treeview
- Input validation and error handling
